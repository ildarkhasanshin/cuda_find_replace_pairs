Plugin for CudaText
Simple plugin automatically saves find/replace pairs.
Next time plugin will automatically insert these values in find/replace fields.
If there is more than one pair in plugin's database - will appear pop-up menu with choice.

Plugin gives few commands in the menu "Plugins / Find-Replace-Pairs":
"List" - show menu-dialog with list of pairs find/replace (* - regex)
"Remove" - delete pair of find/replace which you created before
